# changjietu v0.2.23 更新日志

本版修复后台重切与缓存清理之间的检查—删除竞争窗口；该问题来自源码时序审查，未声称真机复现。

## 新增

- 增加原子清理入口 `pruneIfUnprotected`，将活跃写入目录检查与删除置于同一同步临界区。
- 增加 `CountDownLatch` 并发回归测试，覆盖清理决定后另一编码任务尝试登记的交错。

## 修复

- 避免清理线程释放活跃目录锁后，编码线程插入登记、旧清理继续删除目录。
- 保留已有导出读者租约、24 小时分享宽限、可见文件保护和输出格式，不改变切线算法。

## 验证

- PR #35 的最终提交 `8869c62b`：Android verify and publish #43117768028 通过，Formal state-machine verification #43117768078 通过。
- Android CI 包含 debug lint、JVM 单测、debug 构建、release vital lint 和 bounded formal/negative controls。
- 代码审查确认清理锁获取顺序为活跃目录锁 → ExportFileRetention 锁；当前相关实现未发现反向嵌套获取。尚未完成真机或完整图片 IO 压力验收。
- 正式 APK 发布、签名连续性和远端 SHA-256 需以发布流水线最终结果为准。

## 已知限制
