# changjietu v0.2.16 更新日志

这一版集中改善手动调整切线的实际交互，而不是添加大模型。

## 新增

- 处理页、精细切线页的手柄触控区域扩大到 48dp，视觉圆点继续使用 38dp，方便点中但不让蓝色按钮变得更大。

## 修复

- 修复部分手柄按下又松开（实际并未移动）依然进入不必要的重切/重编码流程。
- 拖动后回到原点不会再触发无意义的提交；若触控被取消，精细编辑恢复拖动前预览坐标。
- 命中区域变大时，仍保持视觉点与切线中心位置对齐。

## 验证

- 新增 4 项纯 Kotlin 切点像素映射回归：原位点按、拖动回原点、实际位移以及非法视口尺寸。
- 新增静态 UI 触控尺寸与取消行为回归，确保 48dp 命中、38dp 视觉尺寸同时成立。
- 每次正式发版通过 Android 单测、Lint、Debug 构建、状态机验证，签名连续性、远端 APK 下载与 SHA-256 回读仍为发布门禁。

## 已知限制

- 尚未获得 Android 真机多刷新率、屏幕旋转、双指和滚动抢手势的完整验证记录。不能将 CI 结果冒充手机端交互合格。
- 自动切点仍可能截断长表格、图表；这版只优化手动切线触控，不重新引入 OCR/ML Kit。
- 现有分享到第三方应用的接收端排列顺序仍可能被重排，ZIP 内文件名仍按逻辑顺序排序。
