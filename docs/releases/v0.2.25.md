# changjietu v0.2.25 更新日志

本版改善长截图分割前的切线检查与设置可读性，重点是让用户看见实际切线附近内容、明确裁边状态，并能删除误加的切线。改动不涉及切点算法和正式导出编码。

## 新增

- 处理页对最多 8 条切线显示局部内容网格，每个预览块展示切线附近的源图像素和准确位置；其他情况仍使用整图预览。
- 精细切线编辑新增「删除当前切线」；删除按 source 坐标映射到当前可见项，裁边外隐藏切线不受影响。
- 手动裁边改为左右、上下双列，新增「应用检测值（含左右）」操作，点击后才启用包含水平裁边的手动数值。
- 高度预设增加文字和颜色双重选中提示。

## 修复

- 将切线拖动手柄从图片中心移至右侧，减少手指遮挡正文；上一条与下一条禁用态、定位按钮更明确。
- 首页合并重复导入说明，历史记录增加进入提示。
- 裁切设置页移除重复的原图宽度、滑块教学文案与预览提示；将「输出格式」改为准确的「画质」说明。
- 明确关闭裁边后手动参数会保留，但不会作用于实际输出，仍提示 JPEG 为有损压缩。

## 已知限制

- 新局部预览使用已有下采样位图，不代表像素级原图放大；精细编辑仍需要用户检查文字和图表是否被切断。
- 复杂图片/图表区域仍可能自动分割不准确；本版未引入 OCR、PNG 无损输出、历史删除管理或撤销栈。
- 右侧拖动手柄、删除操作、双列输入在小屏幕、大字体、深色模式下仍需实机验收。
- 未修改实际 JPEG 编码、切片像素边界、文件路径、分享与清理逻辑。
