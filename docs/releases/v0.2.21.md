# changjietu v0.2.21 更新日志

本版修复后台重切取消或被新任务取代后，已生成但未被编辑器采用的切片缓存目录可能残留的问题。风险依据是协程取消与 IO 完成之间的源码时序；尚未在真实设备上确认发生频率。

## 新增

- 新增 `ReprocessOutputLifecycle`，管理重切输出目录的提交与清理。
- 新增两项 JVM 单元测试：未提交目录及部分文件删除、已提交切片保留。

## 修复

- 重切结果只有通过原子状态比较与交换（CAS）被编辑器采用后，才保留输出目录。
- 取消、被替代或源图片变化导致结果未被采用时，在 `finally` 清理未提交输出。
- 保持现有切线算法、编码、分享行为，不引入 OCR 模型。

## 已知限制

- 缺少可控协程调度的 A/B 重切交错、取消后文件生命周期端到端测试；本版 JVM 测试仅覆盖清理策略。
- 自动切线对图表、图片及复杂排版仍可能不准确；无损 PNG、历史恢复尚未完成。
- 真机安装、导出、分享及反复重切验收尚未完成。
