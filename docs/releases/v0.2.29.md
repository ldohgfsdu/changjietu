# changjietu v0.2.29 更新日志

本版修复清除当前图片后编辑状态没有完全失效的问题。保留既有自动切分算法、图片输出格式、文件分享逻辑和界面布局。

## 新增

- 为 `clearSource()` 增加源码级状态重置回归断言，覆盖手动切线、边距、高清详情及源文件状态。

## 修复

- 清除图片时同步清空旧手动切线和手动边距，避免旧编辑数据残留在无源状态。
- 清除图片时取消尚未完成的高清详情任务并清空旧详情缓存，避免旧任务继续向详情界面提供过期结果。

## 验证

- PR #47 的 Android Debug 单元测试、构建和 Lint 已通过，形式化验证及模拟器首页巡检已通过。
- 新增回归为源码契约测试，不等同于已执行真实设备切线和清除图片交互；正式发布须再次通过 GitHub verify。
- 正式 APK 必须通过与上一正式版相同签名证书的检查，并核对包名、versionCode、远端附件 SHA-256 和大小。真机验收待用户安装后进行。

## 已知限制

- 本版没有改变自动切分图表的识别算法，不能声称已经解决图表截断。
- 未完成真实设备上的清除图片、频繁重切、导出与分享全链路验收。
