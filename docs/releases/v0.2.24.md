# changjietu v0.2.24 更新日志

本版修复连续调整切线时，取消的重切任务可能在 UI 主线程同步删除大量临时切片、导致交互停顿的问题。该风险由源码检查和可执行回归检查确认，尚无真机卡顿时长数据。

## 新增

- 增加取消重切清理调度回归测试：使用阻塞 IO 和 CountDownLatch 验证清理不会占用调用线程。
- 增加取消中清理、已提交文件保留、清理异常后目录注册释放的 JVM 测试。

## 修复

- 将未采用切片目录的递归删除移至 Dispatchers.IO，避免在 viewModelScope 的主线程 finally 中执行磁盘删除。
- 通过 NonCancellable 确保重切协程被取消后，仍完成临时目录清理与活跃写入目录保护释放。
- 保留已有文件租约、分享宽限、输出格式和裁切算法，不引入重型 OCR。

## 验证

- 修复前 Android CI #43171715785：190 项单测中，新增主线程清理回归检查失败（预期红测）；其余 189 项通过。
- PR #36 最新提交 ad6b694c：Android CI #43172225176 通过；Formal Verification #43172225165 通过。
- 验证包含 JVM 单测、Debug 构建、Lint、Release Vital Lint、状态机模型与负对照；新增测试覆盖阻塞清理、取消后继续清理、已提交文件保留、异常释放保护。
- 以上为自动化证据，不等于真实设备上的帧时间测试或所有取消时序均已穷尽。

## 已知限制

- 尚未完成真机快速 A/B 重切、源切换、分享导出及性能验收，UI 卡顿改善幅度未测量。
- 大型图表、图片区域仍可能被自动切线截断；无损 PNG、历史恢复仍待进一步开发。
- 本版没有引入 OCR，也没有改动图片编码质量或切点算法。

## APK 大小

- 以正式发布流水线生成并远端回读的 APK 实际字节数为准，发版前不预填未核验数字。
