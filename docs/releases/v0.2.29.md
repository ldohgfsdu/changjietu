# changjietu v0.2.29 更新日志

本版优先修复清除图片与部分保存失败时的状态恢复问题。保持既有自动切分、原尺寸 JPEG 输出、ZIP 和分享流程。

## 新增

- 保存相册部分成功时，提示已保存和失败数量，并提供「仅重试失败项」。再次保存只处理失败的切片，不重复导出此前成功的文件。
- 为批量保存增加部分失败、异常继续处理、取消传播三类单元回归，覆盖失败切片阅读顺序。
- 增加按 20 条产品体验原则形成的源码审查记录 `docs/UX_AUDIT_20261114.md`。

## 修复

- 清除图片时同步清空旧手动切线与边距，取消旧高清详情任务并清空其缓存，避免清除后继续呈现过期编辑状态（PR #47）。
- 导出中个别切片失败时保留已保存成果，并提供精准重试入口；重试前确认失败切片仍属于当前编辑器（PR #51）。
- 旧图片的保存协程完成后，不再将旧保存状态写入已替换图片的编辑界面（PR #51）。

## 验证

- PR #47 的 Android Debug 单测、构建、Lint、形式化验证和模拟器首页巡检已通过。
- PR #51 的 Android 构建、单测、Lint、模拟器首页与合成图完整导入切分导出回读、形式化状态机验证均通过。
- PR #51 合并到 master 后，新的 Android verify 与形式化验证再次通过（run 43554945806、43554945827）。
- 正式发布流程还须校验本版 versionCode、上一正式 APK 的签名连续性、新 APK 的 SHA-256，以及从 GitHub Release 远端重新下载并逐字节比对附件。

## 已知限制

- 模拟器测试不等于真实 Android 设备验收。部分保存失败后的重试按钮未在真机进行故障注入验证，需要用户安装后复测。
- 未改变自动切点算法，无法保证所有图表、表格和图片完全避开切线，仍允许人工移动切线。
- PR #50 的「换图片时取消旧高清任务」修复尚未合并，不包含在本版中；该 PR 的模拟器验证需要进一步排查。
