# changjietu v0.2.15 更新日志

这一版优先解决已有功能稳定性，让导出期间的文件不被自动删除，同时让每次发布真正写清楚更新内容。

## 新增

- 导出文件临时保护机制：保存相册、打包 ZIP 期间锁定正在读取的切片；分享后保留至少 24 小时。
- GitHub 正式 Release 展示独立的中文版本记录，自动追加真实 APK 大小、SHA-256。

## 修复

- 避免快速重切、保存与 ZIP 打包并发时，缓存清理删除仍在读取的切片。
- 将缓存清理范围限定为超过保留期限且不再处于使用中的旧文件。
- ZIP 临时文件使用毫秒级时间戳，减少同秒多次打包时的名称碰撞。

## 验证

- 新增四项 JVM 回归：并发读者、分享后进程重建、单 ZIP 保护、读者重复释放和超期清理。
- Android CI 运行单测、编译、Lint 和状态机检查；正式 APK 的原签名证书、版本码递增和远端 SHA-256 回读仍是强制发布门禁。
- 未引入任何 OCR、机器学习模型或云端上传；继续使用约 1.6 MB 的轻量技术基线。

## 已知限制

- 文件保留是 App 内 24 小时防误删策略；操作系统主动清除缓存、用户手动清理缓存不受该机制控制。
- 外部 App 的分享读取时序未经过全部真实机型测试，不能保证所有接收端都按原图顺序展示切片。
- 自动切线仍可能穿过连续图表、表格；需手动调整，尚无经过验收的全自动语义识别。
