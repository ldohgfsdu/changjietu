# changjietu v0.2.28 更新日志

本版根据实机反馈，统一取消 App 界面中用于分隔信息的中点标点符号。只调整用户可见文案，不改变布局、触控目标、裁切算法、文件导出逻辑。

## 新增

- 增加 UI 文案回归测试，确保首页、裁切设置、切片结果、精细切线编辑页不再引入这类分隔符。

## 修复

- 「调整切线」中央导航改为简洁的「1/5 定位」，保留原有定位操作。
- 首页最近处理记录使用逗号分隔日期与切片数量。
- 裁切设置页的切片摘要、重叠说明和四边检测值改用逗号。
- 切片结果页的尺寸、选中数量和操作说明采用逗号分隔。

## 验证

- 变更仅涉及 UI 中文文案、源码级回归测试与版本号。
- 合并之前必须通过 Android CI、JVM 单测、Debug 构建、Lint 和 Formal Verification。
- 合并后的正式发布必须重新校验证书连续性、Release 附件与 SHA-256 哈希。

## 已知限制

- 本版不更改自动分割图表的识别精度，不新增图片无损编码或撤销功能。
- 自动化测试不代替真实设备的视觉检查。
