# changjietu v0.2.17 更新日志

针对 v0.2.16 实机录屏反馈，集中修复精细切线编辑器的布局与定位，不增加模型或改动裁切算法。

## 新增

- 红色风险切线与蓝色普通切线都显示检查提示，固定在同一位置；蓝色也不代表图表一定完整。
- 底部始终显示自动/手动切线状态，手动状态提供「恢复自动」。

## 修复

- 风险提示和手动调整状态不再条件插入整块布局，避免它们改变长图滚动视口高度。
- 自动定位不再因视口高度变化重复触发，减少切换切线、首次手动拖动时与显式定位竞争造成的跳动。
- 保留上一条、下一条、当前切线定位、48dp 命中区、38dp 视觉圆点及取消恢复行为。

## 验证

- Issue #28 / PR #29：新增源码布局与自动定位 key 契约回归。对 v0.2.16 基线执行等价断言可复现失败，修复源码通过；这不是设备 UI 测试。
- 正式发布门禁执行 Android 单测、Debug 构建、Lint、release vital lint、有界状态机验证及负对照；签名连续性、远端 APK 下载与 SHA-256 回读必须通过。
- versionCode 19，保持原包名和签名，允许覆盖安装上一正式版。

## 已知限制

- 尚无新版 Android 真机录屏或 Compose UI 运行态测试证明所有切线跳动消失；请重点复验红/蓝切线切换、首次拖动、恢复自动及连续定位。
- 极长图仍受 6000dp 总览高度上限影响，可能纵向压缩；横屏、分屏、放大字体和手势冲突待复验。
- 自动切点仍可能截断图表或连续文字，本版不改变自动切点、导出、文件生命周期，也不重新引入 OCR/ML Kit。
- 第三方接收应用可能重新排序分享图片，ZIP 内文件名按逻辑顺序排序。
