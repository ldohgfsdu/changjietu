# changjietu v0.2.16 更新日志

本版以切线交互为重点，减少手柄难以点中以及没有移动时却触发重复切片的问题，保持轻量 APK。

## 新增

- 总览页与精细切线编辑页的可拖动手柄区域由 38dp 扩大到 48dp，保持蓝色/红色视觉圆点为原来的 38dp。
- 针对手柄触控与释放动作，新增可重复执行的 UI 源码契约回归。

## 修复

- 在总览页仅轻触手柄、没有发生有效像素位移时，不再触发重新切片和文件编码。
- 取消中的拖动不会误触发总览页的提交动作；保留滚动区域与切线手势的原有隔离机制。
- 简化编辑器操作提示、状态文案，减少视觉干扰和不必要的装饰分隔符。

## 验证

- Android 单测、编译、Lint、状态机验证与 APK 签名连续性由 GitHub Actions 强制执行；Release 仍需远端附件及 SHA-256 回读。
- 新增对两个编辑器实际触控尺寸、视觉尺寸、拖动/提交门禁的静态契约测试。
- 无新增第三方模型或网络依赖；本版不修改源图坐标换算、图像压缩方式、保存/ZIP/分享排序。

## 已知限制

- 尚未完成实际机型上的 60/120Hz 拖拽、系统返回、多指触控和旋转冲突验收。代码测试不能替代真机验证。
- 自动切线仍可能穿过完整图表和表格。此版优先改善手动调整效率，并未引入自动视觉语义识别。
- 保存到外部 App 后，接收端可能自行重排图片；推荐使用 ZIP 保持可核验顺序。
