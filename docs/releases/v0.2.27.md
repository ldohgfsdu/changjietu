# changjietu v0.2.27 更新日志

本版直接根据“调整切线”实机截图修复顶部导航过于拥挤、定位控件被大边框包裹的问题。

## 新增
- 新增紧凑的无边框「N/M · 定位」文字操作，保留居中定位能力。

## 修复
- 删除中间「第 N/M 条 定位」的大型边框，改为无边框的「N/M · 定位」文本操作。
- “上一条 / 定位 / 下一条”保持横向排列，保留当前切线居中定位功能与可访问性标签。
- 导航栏从 52dp 收紧到 48dp，左右控件各收窄到 72dp；全部保留至少 44dp 高的触控目标。
- 将风险提示从固定 48dp 空白块改为随内容占高的简短说明；保留红/蓝两种风险状态对应的文字解释。
- 底部编辑操作栏由 56dp 调整至 48dp，让图片获得更多有效显示空间。
- 同步修正定位滚动高度计算，避免导航高度变化后切线定位偏移。
- 更新源码级布局回归测试，防止未来误加大边框或固定高度提示。

## 验证
- 更新仅涉及 Jetpack Compose 界面和 UI 回归测试。
- 自动切线检测、长图分割算法、签名、保存、分享、文件清理逻辑不变。
- PR #39 和合并后的 master 已通过 Android CI、单元测试、Lint 和状态机检查。
- 正式签名 APK 与远端附件哈希仍以重新发布工作流的实际结果为准。

## 已知限制
- 自动化检查不等同于真机布局与触控验收，尤其需要检查大字号和狭窄屏幕。
- 本版只优化编辑界面导航，不修改自动切线识别、导出画质、历史记录等功能。

## APK 大小
- 以实际发布的签名 APK 和远端 SHA-256 回读结果为准。
